How to Use This Application

  1. Open Live SMS Detector to paste any SMS or test sample messages across all 5 models in real time.
  2. Open Analytics to inspect class balance, character length distributions, and top spam/ham terms.
  3. Open Model Comparison to compare metrics, confusion matrices, ROC/PR curves, and global feature importances.

Scope & Safety Notice

This application is an educational screening prototype trained on English SMS messages. It does not visit URLs or guarantee sender authenticity. Never click suspicious links or share OTPs/PINs solely because a message is classified as HAM.

    Methodology & Ensemble Learning

    • Stratified 60/20/20 Split: 60% Training, 20% Validation (for selecting the default model by Spam F1-score), and 20% Held-Out Test.
    • Leakage-Free TF-IDF: Fitted strictly on the training set (1,500 max features, unigrams & bigrams, sublinear TF).
    • Models Evaluated: Decision Tree (single learner baseline), Random Forest (bagging), AdaBoost, Gradient Boosting, and XGBoost.

    Dataset Citation & Limitations

    Almeida, T. A., and Hidalgo, J. M. (2011). SMS Spam Collection. UCI Machine Learning Repository. DOI: 10.24432/C5CC84.

    Limitations: Trained on historical English SMS data. Does not validate live URLs or sender phone numbers.
