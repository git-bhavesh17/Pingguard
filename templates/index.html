Scope & AI Ethics Notice

PingGuard is an educational machine learning prototype running 100% locally. User-entered SMS texts are never logged or sent to external servers. A HAM prediction is a statistical estimate and never a guarantee of link or sender safety.

    Key Enhancements & Architecture Upgrades

    Loading hybrid feature statistics...

    Supervised Learning

    Linear SVM, Logistic Regression & Entropy Tree

    Added L2 Logistic Regression and Calibrated Linear SVM (strongest linear baselines for sparse text) and configured Decision Tree with Entropy / Information Gain splits.

    Unsupervised Learning

    PCA 2D Projection & K-Means Elbow Clustering

    Applied Principal Component Analysis (PCA) to visualize Ham vs. Spam separation in 2D and K-Means with the Elbow Method to discover hidden spam sub-categories automatically.

    Ensemble & Feature Engineering

    Hybrid Word+Char TF-IDF, Soft-Voting & Threshold Tuning

    Combined Word TF-IDF with Character N-Grams (3–5 chars) to catch obfuscated text, tuned decision cutoffs on the validation set, and added a Weighted Soft-Voting Meta-Ensemble.

    Reinforcement Learning & AI Ethics

    Q-Learning Screening Agent & Bias/Privacy Audit

    Implemented a Bellman Q-Learning agent mapping risk states to Allow/Quarantine/Block actions with live user feedback, alongside False Positive/Negative ethics monitoring.

    Ethics in AI — Bias & Privacy Audit

    False Positive Rate (Ham Blocked) --

    Measures how often legitimate messages are wrongly flagged as spam.

    False Negative Rate (Spam Missed) --

    Measures how often suspicious spam slips through as Ham.

    • Dataset Bias Awareness: Historical English SMS corpus may underperform on regional slang or non-English texts.
    • Privacy by Design: Zero cloud APIs, zero external telemetry, and zero database logging of user-submitted SMS texts.
    • Human-in-the-Loop: The Q-Learning agent includes a Quarantine / Review action for borderline scores instead of silently deleting messages.

    Machine Learning Architecture

    • Supervised Classification: Logistic Regression, Linear SVM, and Entropy Decision Tree.
    • Unsupervised Analysis: PCA 2D dimensionality reduction and K-Means Clustering with Elbow Method.
    • Ensemble Learning: Random Forest (Bagging), AdaBoost, Gradient Boosting (GBM), XGBoost, and Soft-Voting Meta-Ensemble.
    • Reinforcement Learning & Ethics: Q-Learning MDP Agent with live Bellman feedback and AI Bias/Privacy Audit.

    Dataset Citation & Limitations

    Almeida, T. A., and Hidalgo, J. M. (2011). SMS Spam Collection. UCI Machine Learning Repository. DOI: 10.24432/C5CC84.

    Limitations: Trained on historical English SMS data. Does not validate live URLs or sender phone numbers.
