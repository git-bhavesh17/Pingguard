# pingguard
PingGuard is an Ensemble Learning-Based SMS Spam Detection and Safety Dashboard that classifies messages as HAM (legitimate) or SPAM using the UCI SMS Spam Collection dataset.

We apply text preprocessing and TF-IDF, then compare five machine learning algorithms: Decision Tree, Random Forest, AdaBoost, Gradient Boosting and XGBoost.(Bagging and Boosting)
Key Results: Random Forest achieved the best reported performance with 98.16% test accuracy.

The web application provides live SMS prediction, spam-score estimation, warning clues, data visualizations and model comparison through an interactive dashboard.
